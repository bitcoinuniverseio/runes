 # Runes Documentation Changelog

 Chronological record of documentation releases, protocol milestones, and platform enhancements.

  
Documentation releases follow Semantic Versioning (SemVer 2.0.0).
 ## Documentation Platform 3.0.0 (2026-09-02)

 Major architectural expansion and interactive tooling release.  - <strong>Runic Ledger Theme:</strong> Implemented accessible, high-contrast light and dark visual system with engraved borders and responsive 3-column layout.
 - <strong>Shared Protocol Core:</strong> Released `@bitcoinuniverse/runes-tools` pure TypeScript library powering all browser tooling, simulations, and CLI.
 - <strong>Runestone Studio:</strong> Built 8 interactive modes including script decoder, raw tx parser, visual composer, allocation simulator, byte scrubber, side-by-side comparison, cenotaph autopsy, and relay size audit.
 - <strong>Guided Safety Wizards:</strong> Released Transfer Safety Wizard, Mint Readiness Wizard, and Etching Commitment Planner.
 - <strong>Learning Academy:</strong> Added 7 curriculum tracks from basics to indexer development with interactive quizzes and local progress saving.
 - <strong>Real Transaction Atlas:</strong> Documented 12 verified mainnet transactions including Genesis etchings, multi-rune transfers, and cenotaph burns.
 - <strong>Agent-Ready Suite:</strong> Published `llms.txt`, `llms-full.txt`, machine-readable schemas, and local stdio MCP server.
 - <strong>Offline-First PWA:</strong> Added service worker, web app manifest, and self-contained offline download bundle.
  ## Documentation 2.0.0 (2025-06-15)

 Authoritative reference restructuring and browser decoder.  - Formalized numbered specification rules R1 through R47.
 - Added full 24-vector conformance suite (V1–V8, C1–C14, N1–N2).
 - Introduced client-side browser Runestone decoder.
 - Added Implementer Reference with indexer pipeline and reorg safety guidance.
  ## Documentation 1.0.0 (2024-04-20)

 Genesis release coincident with Bitcoin block 840,000.  - Initial documentation of Runes protocol principles, tags, and edicts.
 - Coverage of Genesis rune `UNCOMMON•GOODS`.

This documentation platform uses Semantic Versioning (`MAJOR.MINOR.PATCH`):

  - <strong>MAJOR:</strong> Substantial platform rewrites, major design overhauls, or breaking protocol upgrades.
 - <strong>MINOR:</strong> New tooling modes, educational tracks, transaction atlas cases, or protocol rule expansions.
 - <strong>PATCH:</strong> Typo fixes, explanatory clarifications, or link updates.
