What Are Runes?

Runes is a simple, UTXO-native fungible token protocol designed specifically for Bitcoin. Unlike account-based token standards or protocols that store arbitrary data blobs in transaction witnesses, Runes operates directly on Bitcoin's Unspent Transaction Output (UTXO) set.

A Runes transaction communicates state transitions through a single OP_RETURN output followed by OP_13 (push byte 0x5d). This payload, called a Runestone, contains unsigned LEB128 varints specifying etchings, mints, and transfers (edicts).

Prunable and Safe for Node Operators

Because Runestones are carried in standard OP_RETURN outputs, Bitcoin nodes can prune them immediately from the UTXO set. Runes does not leave unspendable "dust" UTXOs on the blockchain to store token balances. All token balances reside in legitimate, spendable Bitcoin UTXOs.

The UTXO Mental Model

Every Runes transaction operates as a deterministic, single-step state machine:

  1. Gather: All rune balances across all spent inputs drain into a transaction-wide unallocated balance pool.
  2. Mint or Etch: Any active mint instruction or etching premine adds new units to the unallocated pool.
  3. Edict Allocation: The Runestone executes an ordered list of edicts, assigning specified amounts of runes from the pool to specified output indices.
  4. Remainder Routing: Any runes remaining in the pool after edicts execute route automatically to the output specified by the Pointer (Tag 22), or fall back to the first non-OP_RETURN output.
  5. Cenotaph Safety: If the Runestone contains malformed varints, unrecognized even tags, or out-of-bounds outputs, the entire transaction is classified as a Cenotaph, and all input runes are permanently burned.

Ecosystem & Protocol Support

The Runes protocol is supported natively across the Bitcoin developer ecosystem:

  • Reference Implementation: Casey Rodarmor's ord (version 0.29.0+).
  • Ecosystem Indexers: ordinals, Unisat Indexer, Oyl Indexer.
  • Explorers: ordinals.com, mempool.space, runescan.io.
  • Client Tooling: @bitcoinuniverse/runes-tools (TypeScript), ordinals crate (Rust).
