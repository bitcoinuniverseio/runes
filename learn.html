Runes Learning Academy

Structured curriculum for developers, node operators, wallet architects, and Bitcoin protocol enthusiasts.

7 specialized curriculum tracks · Interactive quizzes · Local private progress tracking.

Welcome to the Runes Learning Academy. Each track provides concise, technical lessons followed by consensus verification quizzes linked directly to the normative specification rules.

Curriculum Tracks

Track 1 ~10 min

Runes in 10 Minutes

Audience: Anyone new to Runes who wants an accurate, hype-free mental model.

Explain how runestones live in Bitcoin outputs, how balances move, and why cenotaphs exist.

Track 2 ~15 min

Inspect a Runestone Safely

Audience: Users, operators, and analysts verifying raw scripts before signing or indexing.

Dissect carrier scripts byte by byte, extract varints, decode tags, and identify flaws.

Start Track 2 →
Track 3 ~20 min

Transfer Runes Safely

Audience: Users and wallet integrators sending or batching rune balances.

Construct edicts, handle delta encoding, avoid change loss, and calculate splits safely.

Start Track 3 →
Track 4 ~15 min

Understand and Evaluate a Mint

Audience: Users evaluating mint eligibility and developers building mint checkers.

Calculate effective mint start and end windows, evaluate caps, and detect silent mint failures.

Start Track 4 →
Track 5 ~25 min

Plan an Etching

Audience: Creators, asset architects, and tooling builders creating new runes.

Encode rune names, calculate commitment data pushes, check unlock schedules, and prevent supply overflow.

Start Track 5 →
Track 6 ~30 min

Build a Wallet or Application Integration

Audience: Wallet architects, frontend engineers, and Bitcoin backend developers.

Integrate @bitcoinuniverse/runes-tools, manage cardinal inputs, build safe review screens, and prevent balance destruction.

Track 7 ~35 min

Build or Operate a Runes Indexer

Audience: Backend engineers and infrastructure operators indexing Bitcoin blocks.

Implement state transitions, handle reorgs via savepoint rewinding, compute allocations, and maintain zero-drift consensus.

Private & Client-Side Storage

Every lesson in this curriculum is grounded directly in Casey Rodarmor's ord 0.29.0 reference source code. You will never encounter marketing conjecture, vague analogies, or conflicting rules.
