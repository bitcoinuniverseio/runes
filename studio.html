The 8 Diagnostic Modes

  1. Compose Runestone: Visually configure etchings, open mint terms, pointer routing, and edicts. Emits verified script hex and checks standard Bitcoin relay policy (83-byte limit).
  2. Decode Script: Paste any raw OP_RETURN script hex to inspect concatenated payload pushes, LEB128 decoded integers, and parsed message fields.
  3. Inspect Raw Tx: Paste raw serialized Bitcoin transaction hex to automatically extract inputs, parse outputs, and decipher candidate Runestones in place.
  4. Simulate Allocation: Test complex multi-input, multi-output state transitions. Models edict execution order, balance sweeps, remainder pointers, and cenotaph burns.
  5. Explain Bytes: An interactive byte scrubber. Hover or tap individual hex byte pairs to inspect the exact opcode, varint, or tag definition.
  6. Compare Two Runestones: Diff two script payloads side-by-side to detect tag discrepancies, edict order differences, or size optimizations.
  7. Cenotaph Autopsy: Craft or inspect malformed scripts to pinpoint the exact failing byte offset, stage, and controlling rule.
  8. Size & Policy Analysis: Measure script weight, data push limits, and relay policy compliance.

Browser Engine & Performance

The entire Studio is driven by the typed @bitcoinuniverse/runes-tools pure TypeScript library. It runs 100% locally in your browser session with sub-millisecond execution times and zero external API calls.
