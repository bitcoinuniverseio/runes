Common Transfer Pitfalls

  • Sending Change to OP_RETURN: Setting a pointer or edict to the OP_RETURN output burns all runes sent there permanently.
  • Output Count Overflow: Specifying an edict output index greater than or equal to total outputs (except the split sentinel) triggers cenotaph flaw EdictOutput, burning all input runes.
  • Forgetting Change: If no pointer is specified, change falls back to the first non-OP_RETURN output, which may inadvertently mix runes with Bitcoin fees or recipient outputs.

Consensus Guarantees

Conservation of Supply (Rule R40)

In a valid transaction without mints or etchings, the sum of all output rune balances plus explicit burns exactly equals the sum of all input rune balances.
